# DeepSeek Prompt Generator & CoT Studio

> High-precision Chain-of-Thought (CoT) and System Prompt builder optimized for DeepSeek-R1 and DeepSeek-V3.

## Features
- **Dual Model Engine**: Dedicated toggle between DeepSeek-R1 (recursive `<think>` reasoning) and DeepSeek-V3 (direct rapid execution).
- **XML Tag Semantics**: Automatic wrapping of `<role>`, `<reasoning_directive>`, `<instructions>`, `<context>`, and `<constraints>`.
- **Negative Constraints**: Zero filler, self-verification, zero hallucinated APIs, strict output typing.
- **Client-Side Only**: 100% private, zero-backend, runs entirely in the browser.
- **PaceBowl Suite Matrix Integration**: Shared cross-subdomain theme (dark/light) & language (EN/ZH) sync.

## Deployment
Hosted on Cloudflare Pages (`deepseek.pacebowl.com`).
